1. Get the application URLs by running these commands:

{{- if .Values.traefik.ingressRoute.dashboard.enabled }}
  Traefik Dashboard: https://traefik.{{ .Values.global.domain }}
{{- end }}

{{- if .Values.portainer.ingress.enabled }}
  Portainer: https://{{ .Values.portainer.ingress.host }}
{{- end }}

{{- if .Values.trilium.ingress.enabled }}
  Trilium Notes: https://{{ .Values.trilium.ingress.host }}
{{- end }}

{{- if .Values.grafana.ingress.enabled }}
  Grafana: https://{{ .Values.grafana.ingress.host }}
  Default credentials: admin / {{ .Values.grafana.env.GF_SECURITY_ADMIN_PASSWORD }}
{{- end }}

{{- if .Values.prometheus.ingress.enabled }}
  Prometheus: https://{{ .Values.prometheus.ingress.host }}
{{- end }}

{{- if .Values.jenkins.ingress.enabled }}
  Jenkins: https://{{ .Values.jenkins.ingress.host }}
{{- end }}

{{- if .Values.matrix.ingress.enabled }}
  Matrix Synapse: https://{{ .Values.matrix.ingress.host }}
{{- end }}

2. Monitor your deployments:
   kubectl get pods -n {{ .Release.Namespace }}
   kubectl get ingress -n {{ .Release.Namespace }}

3. Check Traefik dashboard (if enabled):
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }}-traefik 8080:8080
   Then visit: http://localhost:8080

4. To access services locally without ingress:
{{- if .Values.portainer.enabled }}
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "sloboda-stack.fullname" . }}-portainer 9000:9000
{{- end }}
{{- if .Values.grafana.enabled }}
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "sloboda-stack.fullname" . }}-grafana 3000:3000
{{- end }}
{{- if .Values.prometheus.enabled }}
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "sloboda-stack.fullname" . }}-prometheus 9090:9090
{{- end }}

Note: Make sure your DNS records point to your K3s cluster's external IP for the ingress hosts to work properly.
